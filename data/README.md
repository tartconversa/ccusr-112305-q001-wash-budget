# 资料口径

日内时段从 0 开始，每段 60 分钟，日期为当地经营日。水表记录是累计升数。表名变化表示独立表底，两个计数不能直接相减。individual 是同日连续记录的独立支路，仅覆盖有实测值的日子。
清洗记录给出实物实际经历，可以与排程中的预留用途不同。料筐可共同使用预冲洗，但“单洗”料筐必须单独用机器。检测单的 version 按同一单号订正，allowed_use 是回用水可用于的料筐等级。常用和节水程序允许普通料筐并洗。单洗程序独用一台机器的一个时段。罐内受许可的回用水可跨班，carry_from 为物业实际批准的往绩交接。超出出水、回收或使用记录能对上的计量边界留作未归属。洗护排程按料筐整批承接，不拆领件预约。任何已交接实物以柜台回单为准。

跨经营日交接测量在水表记录中另列，排程里的日期和时段共同确定预约窗口。
